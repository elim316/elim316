## Agentic systems and developer tooling

### [Jetski Agent Tracer Plugin](https://github.com/elim316/Jetski-Agent-Tracer-Plugin)
A real-time execution graph and architecture visualiser for autonomous agents, built with Python, Vis.js, and SVG. It tails live JSONL transcripts on a 1.5s loop and renders them into three-lane swimlanes across Timeline, Architecture, and Simplified views, with tool-failure detection and subagent drill-down.

### [Jetski Harness](https://github.com/elim316/Jetski-Harness)
A unified mission control UI plugin for Jetski built with Python Connect-RPC and vanilla JavaScript. It combines a customisable 2x2 Bento grid, multi-session agent chat, cross-pane tool syncing with Agent Tracer, cron automation controls, and live token, cache-hit, and cost telemetry.

### [Smart Meeting Prep and Dossier Agent](https://github.com/elim316/Jetski-Meeting-Prep-Agent)
A two-stage scheduled agent that researches upcoming external and cross-functional meetings across Calendar, Gmail, Chat, Drive, and the People Directory to draft cited one-page briefing docs and stateless T-1h reminders. It includes a 5-scenario, 36-check mock test harness with an automated linter that flags hallucinated names, bugs, and URLs.

## Full-stack and cloud applications

### [EduVerse](https://github.com/elim316/eduverse)
Awarded 2nd Place Overall at NUS LifeHack 2025. A full-stack adaptive learning platform built with Next.js, TypeScript, and Python that pairs a teacher-controlled assignment workflow with a deep Knowledge Tracing backend to personalise revision materials and question routing.

### [MINDSync (Lobang-Octagon)](https://github.com/elim316/Lobang-octagon)
Built for Hack4Good. A centralised multi-branch event and volunteer management platform in TypeScript and React for MINDS, replacing scattered spreadsheets and forms with unified event scheduling, role-based signups for staff, caregivers, and volunteers, and live coverage tracking.

### [Multi-Cloud Serverless App](https://github.com/elim316/multi-cloud-serverless-app)
A full-stack serverless web application built with React, Vite, Supabase, AWS, Terraform, and GitHub Actions. It implements authenticated CRUD workflows, real-time state synchronisation across browser tabs, and automated CI/CD deployment.

### [Panasonic Commercial HVAC Control Dashboard](https://github.com/elim316/Panasonic-HVAC-Dashboard-overview)
Case study from an industry collaboration with Panasonic. Built a centralised web interface using Svelte, Three.js, Node.js, and WebSockets to monitor commercial air-conditioning units, stream energy consumption data, and visualise unit behaviour on an interactive 3D floor plan.

### [OnlyNotes](https://github.com/elim316/OnlyNotes-Note-Sharing-Application)
An Android application built with Kotlin, Jetpack Compose, and Firebase using MVVM architecture. Students can create and share study notes, attach files, join location-based study groups, and collaborate in real-time discussion threads.

## Machine learning and multimodal AI

### [Uncertainty Quantification and Explainable AI for Battery Analytics](https://github.com/elim316/UQ-XAI-battery-analytics)
Research project published in IEEE Xplore. Applies Adaptive Conformal Inference (ACI), calibration metrics (PICP, ECE), and post-hoc explainability (SHAP, LIME) to convolutional neural networks for battery state-of-health estimation inside a cognitive digital twin.

### [TransportGPT](https://github.com/elim316/TransportGPT)
Built for the NUS NCS Innovation Challenge 2024. Combines live traffic camera feeds, YOLOv3 vehicle detection, predictive modelling, and LangChain LLMs to detect road congestion and generate plain-English routing updates.

### [Operation Guardian (DSTA BrainHack 2024)](https://github.com/elim316/TIL-AI-brainhack2024-project-overview)
A multi-stage defence pipeline built for TIL-AI 2024 that chains noisy-speech transcription (ASR), spaCy and NLTK entity extraction to turn spoken target descriptions into structured commands, and computer vision target detection.

### [Brain Tumour MRI Classification](https://github.com/elim316/Brain-Tumour-Classification)
A medical imaging pipeline in PyTorch using EfficientNet-B3 transfer learning, data augmentation, and class balancing to classify brain MRI scans across glioma, meningioma, pituitary tumour, and healthy classes.
