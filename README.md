## Agentic Systems, Observability & Developer Tooling

- **[Jetski Agent Tracer Plugin](https://github.com/elim316/Jetski-Agent-Tracer-Plugin)** — `Python` · `Vis.js` · `SVG` · `SSE / JSONL`  
  Real-time execution DAG and architecture visualiser for autonomous agents. Parses live JSONL trajectories via a 1.5s delta-tail stream into interactive 3-lane swimlanes (**Timeline**, **Architecture**, and **Simplified** views), with deterministic tool-failure detection and inline subagent trajectory drill-down.

- **[Jetski Harness (Mission Control UI)](https://github.com/elim316/Jetski-Harness)** — `Python` · `Connect-RPC` · `JavaScript` · `CSS Grid`  
  Unified mission control plugin combining a customisable 2×2 Bento grid, multi-session agent chat, cross-pane tool click-to-sync with Agent Tracer, cron/daemon automation controls, and live token, context-cache hit rate, and cost telemetry.

- **[Smart Meeting Prep & Dossier Agent](https://github.com/elim316/Jetski-Meeting-Prep-Agent)** — `Python` · `Multi-Corpus MCP` · `Eval Harness`  
  Two-stage autonomous workflow that researches external and cross-functional meetings across Calendar, Gmail, Chat, Drive, and People Directory to generate cited 1-page briefing docs and stateless T-1h reminders. Includes a **5-scenario, 36-check mock evaluation harness** with automated entity/URL hallucination linting.
